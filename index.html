User Manual

✔ Sorting Algorithms

Visualize how different sorting algorithms organize data from smallest to largest value.

  1. Select the "Sorting" tab at the top
  2. Choose a sorting algorithm from the dropdown (Bubble, Selection, Insertion, Merge, or Quick Sort)
  3. Adjust the speed slider to control animation speed
  4. Click "Play" to watch the algorithm sort the bars
  5. Observe the color changes: Orange = comparing, Red = swapping, Green = sorted
  6. View real-time statistics showing comparisons and swaps
  7. Click "Generate New" to create a fresh random dataset

✔ Searching Algorithms

Watch how algorithms find a specific target number in a dataset.

  1. Select the "Searching" tab at the top
  2. Choose between Linear Search or Binary Search
  3. A random target number will be automatically selected
  4. Click "Play" to start the search visualization
  5. Orange highlights show which element is being checked
  6. Green highlight indicates the target has been found
  7. Binary Search automatically sorts the array first for optimal searching

✔ Pathfinding Algorithms

Explore how algorithms find the shortest path between two points on a grid.

  1. Select the "Pathfinding" tab at the top
  2. Choose between BFS (Breadth-First Search) or DFS (Depth-First Search)
  3. Green cell = Start position, Red cell = End position
  4. Click and drag on empty cells to draw walls (obstacles)
  5. Click on walls again to remove them
  6. Click "Play" to watch the algorithm find the shortest path
  7. Purple cells show visited areas, Blue cells show the final path
  8. Use "Generate New" to reset the grid with new start/end positions

✔ Control Panel

Master the control options available for all visualizations.

  1. Algorithm Dropdown: Select which algorithm to visualize
  2. Generate New: Creates fresh random data for visualization
  3. Play: Starts the algorithm visualization
  4. Pause: Temporarily stops the animation (click again to resume)
  5. Reset: Stops visualization and returns to initial state
  6. Speed Slider: Adjust animation speed from slow to fast
