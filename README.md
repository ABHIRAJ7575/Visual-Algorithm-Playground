# Visual-Algorithm-Playground

## What is this thing? 

So basically, I got tired of staring at my DSA textbook wondering "what the hell is Bubble Sort actually doing?" and decided to make colorful bars dance on my screen instead. Much better use of time, if you ask me.
This is a fully functional algorithm visualizer that'll show you how sorting, searching, and pathfinding algorithms work. And yes, before you ask - Claude helped me build this. I'm not ashamed. We live in 2025, people. If you're still manually writing nested for-loops without AI assistance, I respect the hustle but also... why?

## Features (that actually work, surprisingly 🤷‍♂️)

**Sorting Algorithms** - Watch bars go brrr
- Bubble Sort (the one everyone learns first and never uses)
- Selection Sort (slightly better but still painfully slow)
- Insertion Sort (good for small arrays, your prof says)
- Merge Sort (the "I'm smart" algorithm)
- Quick Sort (lives up to its name, usually)

**Searching Algorithms** - Finding needles in haystacks since forever
- Linear Search (the "I'll just check everything" approach)
- Binary Search (for when you actually want efficiency)

**Pathfinding** - Because mazes are fun
- BFS (Breadth-First Search - the completionist)
- DFS (Depth-First Search - the rebel who doesn't guarantee shortest path)

You can draw walls with your mouse like you're playing Paint but for nerds. 😒

## How to use this

1. Open the HTML file in a browser (any browser, I'm not picky)
2. Click the "User Manual" button if you're confused
3. Pick an algorithm from the dropdown
4. Smash that Play button
5. Watch the magic happen
6. Feel smart
7. Realize you still don't fully understand Big O notation
8. Repeat

Pro tip: The speed slider exists. Use it. Some algorithms are painfully slow and you don't have all day.

## Known Issues (aka features)

- If you spam the Play button, weird things happen. Don't do that.
- The grid pathfinding might lag on slower computers. Get a better computer.
- Sometimes DFS finds the weirdest paths. That's not a bug, that's DFS being DFS.
- I haven't added A* pathfinding yet because I value my mental health
